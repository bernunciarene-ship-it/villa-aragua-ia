# Texto sobre imagem

## Regra geral: menos é mais legível

Texto sobreposto existe para ser lido em menos de dois segundos, rolando o feed no celular. Se precisar de mais tempo que isso para ler, o texto está complexo demais para o formato.

## Headline curta

- 3 a 6 palavras, mesma lógica de `villa-aragua-copywriting-conversion/references/headlines-ctas.md` — concreta, sensorial ou factual, nunca genérica.
- Uma ideia por imagem. Se a peça precisa comunicar duas ideias (ex.: café + piscina), são dois criativos, não um com texto duplicado.
- Preferir texto que já existe como título de anúncio aprovado (ex.: "Piscina privativa só para vocês", "Café da manhã na acomodação") — reaproveitar o que já funciona em vez de reinventar a cada peça.

## Poucas palavras — limite prático

- Post de feed: até ~6-8 palavras sobrepostas na imagem.
- Story: ainda menos — o formato é consumido em menos tempo que o feed.
- Se o CTA também estiver escrito na imagem (além do botão nativo do anúncio), manter separado da headline, nunca competindo pelo mesmo espaço visual.

## Contraste legível

- Texto claro sobre fundo escuro, ou texto escuro sobre fundo claro — nunca texto de cor próxima à da imagem por trás (ex.: texto branco sobre céu claro).
- Se a foto de fundo for muito "cheia" (muitos elementos, muita luz variando), usar uma faixa sólida ou leve escurecimento atrás do texto — nunca escurecer a imagem inteira a ponto de perder a cena (ver regra de nunca recomendar imagem escura em `checklist-criativo.md`).

## CTA simples

- O texto do botão/CTA sobreposto (quando existir, além do botão nativo do Meta Ads) segue os mesmos CTAs fortes já definidos em `villa-aragua-copywriting-conversion/references/headlines-ctas.md` — nunca "saiba mais", "clique aqui".
- Um único CTA por peça — nunca duas chamadas de ação competindo (ex.: "Reserve agora" e "Siga-nos" na mesma imagem).

## Evitar fonte difícil

- Fonte legível mesmo em miniatura — nada de caligrafia decorativa ou fontes muito finas para o texto principal.
- Consistência de fonte entre peças da mesma campanha, para o público reconhecer visualmente "isso é Villa Arágua" mesmo sem ler o texto.

## Hierarquia visual

Ordem de leitura em uma peça com texto: (1) a imagem/cena primeiro capta a atenção, (2) a headline reforça o gancho, (3) o CTA indica o próximo passo. Nenhum desses três elementos deve competir em tamanho/destaque com os outros — o olho precisa percorrer essa ordem sem esforço.

## Texto diferente para Pousada e Casa

O texto sobreposto precisa reforçar, nunca borrar, a diferença de produto:

- Pousada: palavras como "café", "suíte", "Mariscal pertinho", "pousada".
- Casa: palavras como "privativa", "só para vocês", "até 6 pessoas", "casa completa".

Nunca usar uma headline genérica ("Villa Arágua — sua hospedagem em Bombinhas") em uma peça que já tem imagem de um produto específico — o texto precisa nomear ou reforçar claramente qual produto está na tela.

## O que nunca fazer

- Nunca cobrir elementos importantes da cena (rosto, piscina, prato do café) com o bloco de texto.
- Nunca usar texto para inventar uma condição comercial ("Últimas vagas!", "50% OFF") sem base real aprovada.
- Nunca empilhar título + subtítulo + CTA + selo/badge decorativo — isso satura a peça e derruba a leitura rápida.
