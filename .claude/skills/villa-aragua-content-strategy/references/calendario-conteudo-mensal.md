# Calendário de conteúdo mensal

Modelo para organizar todos os temas planejados no tempo, cobrindo todos os canais (não só Instagram — para o calendário específico de Instagram, ver `villa-aragua-social-media-manager/references/calendario-editorial.md`, que este calendário alimenta).

## Modelo de linha do calendário

| Campo | O que preencher |
|---|---|
| **Tema** | O assunto específico do conteúdo (ex.: "Piscina compartilhada x piscina privativa") |
| **Pilar** | Um dos 12 pilares de `pilares-conteudo-villa.md` |
| **Formato** | Artigo de blog, página de site, seção de guia digital, post/reel/story (Instagram), anúncio (Meta Ads), mensagem de WhatsApp |
| **Objetivo** | Qual etapa da jornada esse conteúdo serve (`jornada-conteudo-hospede.md`) e qual tipo (informativo/inspiracional/comparativo/comercial) |
| **Público** | Casal, família, grupo, hóspede antigo, ou geral |
| **Canal** | Onde será publicado primeiro (site, blog, Instagram, WhatsApp, Meta Ads) |
| **CTA** | Ação esperada (nenhuma, ler mais, chamar no WhatsApp, seguir perfil) |
| **Skill indicada para execução** | Qual skill escreve/produz a peça final (ver `briefings-para-outras-skills.md`) |

## Como montar o calendário do zero para qualquer mês

1. Verificar o status sazonal do mês (`temas-sazonais-feriados.md`) — reabertura, feriado com/sem oferta, baixa/média/alta temporada.
2. Selecionar 2-4 temas por semana, equilibrando os quatro tipos de conteúdo (informativo/inspiracional/comparativo/comercial) na proporção sugerida em `pilares-conteudo-villa.md` (~35/30/20/15).
3. Garantir que Pousada e Casa Arágua aparecem em algum momento do mês, sem se misturar no mesmo conteúdo (exceto peça comparativa explícita).
4. Verificar lacunas: algum pilar não apareceu no mês? Algum cluster de região ficou de fora por muito tempo? Algum perfil (casal/família/grupo) não foi endereçado?
5. Preencher a coluna de skill de execução para cada linha, deixando claro que este calendário é o planejamento — a produção acontece em outra skill.

## Como identificar lacunas de conteúdo

- Revisar os 12 pilares (`pilares-conteudo-villa.md`) e marcar quais não tiveram conteúdo nos últimos 60-90 dias.
- Revisar os clusters de região (`clusters-bombinhas-mariscal.md`) e marcar quais nunca foram cobertos.
- Revisar as dúvidas/objeções mais frequentes (`duvidas-objeções-como-conteudo.md`) e marcar quais ainda não têm conteúdo de resposta publicado.
- Cruzar com `villa-aragua-campaign-analytics` quando disponível: temas que geraram bom avanço no funil merecem variação/continuação; temas sem repercussão nenhuma merecem revisão de abordagem antes de repetir.

## Como usar este arquivo na prática

1. Usar o modelo de linha para qualquer novo tema que entrar no planejamento.
2. Montar o calendário mês a mês, cruzando sazonalidade, pilares e lacunas.
3. Ao fechar o calendário do mês, gerar os briefings correspondentes (`briefings-para-outras-skills.md`) para cada linha.
