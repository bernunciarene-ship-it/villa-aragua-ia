# Base Visual de Turismo — TUR (Villa Arágua)

**Natureza deste arquivo:** catálogo técnico das fotos de turismo/Bombinhas/Mariscal aprovadas por Renildo para uso comercial e de concierge. Primeira leva, resultado da varredura visual turística e da validação manual feita com Renildo. Este arquivo não cria automação, não altera WhatsApp, não altera Meta Ads e não substitui aprovação humana para novas fotos.

**Fonte textual de curadoria:** `ROTEIROS_SUGERIDOS_BOMBINHAS.md` — toda copy e regra de cuidado usada aqui deve permanecer consistente com esse documento.

**Padrão de código:** `TUR-<LOCAL>-<NN>`, provisório. **Nunca usar `AT-*`** — esse namespace pertence exclusivamente aos ativos de acomodação já cadastrados em `GUIA_ATIVOS_COMERCIAIS_WHATSAPP_VILLA_ARAGUA.md`.

**Escopo desta versão:** 6 fotos aprovadas por Renildo. `TUR-MARISCAL-03` (vista-aerea-praia-mariscal.jpg, pasta GMN) ficou de fora desta leva porque Renildo não localizou a imagem — não incluída no catálogo abaixo.

## 3. Regras de manutenção

- Todo novo código `TUR-*` só entra neste catálogo após aprovação humana explícita de Renildo, seguindo o mesmo padrão de validação usado nesta primeira leva.
- Nenhum código `TUR-*` substitui ou se mistura com os códigos `AT-POU-*`/`AT-CAS-*` de acomodação — turismo complementa a venda, nunca substitui foto de acomodação.
- Qualquer alteração de status (ex.: de "aprovada com ressalva" para "aprovada", ou inclusão de nova foto) deve ser registrada aqui com a mesma estrutura de tabela.
